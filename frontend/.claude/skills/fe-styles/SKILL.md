# Стили

Tailwind CSS v4, css-first. Файла `tailwind.config` нет — вся конфигурация
в `frontend/src/app/styles/index.css`.

## Цвета — только токены

Токены объявлены через переменные темы Telegram (`--tg-theme-*`), которые SDK
проставляет на `:root`. Цепочка такая:

```
тема телефона → тема Telegram-клиента → --tg-theme-* → токены приложения
```

Из этого следует главное правило: **светлую и тёмную тему не верстают отдельно.**
Пишешь один набор классов на токенах — обе темы получаются сами.
Класс `.dark` на `<html>` ставится автоматически, писать `dark:` не нужно.

| Токен                                        | Для чего                                |
| -------------------------------------------- | --------------------------------------- |
| `bg-background` / `text-foreground`          | фон и текст экрана                      |
| `bg-card` / `text-card-foreground`           | карточки, секции                        |
| `bg-primary` / `text-primary-foreground`     | основное действие (цвет кнопок клиента) |
| `bg-secondary` / `text-secondary-foreground` | второстепенный фон                      |
| `bg-muted` / `text-muted-foreground`         | подписи, подсказки, disabled            |
| `text-link`                                  | ссылки                                  |
| `bg-destructive`                             | удаление, блокировка, ошибки            |
| `border-border` / `border-input`             | разделители и рамки полей               |
| `ring-ring`                                  | фокус                                   |
| `bg-brand` / `text-brand-foreground`         | фирменный акцент «Блізкі»               |

Запрещено:

```tsx
<div className="bg-white text-black" />        // ❌ сломается в тёмной теме
<div className="bg-[#f2607c]" />               // ❌ произвольный цвет
<div style={{ color: '#333' }} />              // ❌ инлайн-цвет
<div className="dark:bg-gray-900" />           // ❌ тема приходит из Telegram
```

Нужен цвет, которого нет в таблице — добавь токен в `index.css` (в `:root`,
`.dark` и `@theme inline`) и только потом используй.

## Как проверить обе темы

В браузере в правом нижнем углу есть переключатель темы (только в dev-сборке
с `VITE_MOCK_TELEGRAM=1`): «как в системе» / светлая / тёмная. Выбор сохраняется
между перезагрузками.

Любую новую верстку прогоняй по всем трём положениям. Типичные находки:
текст, слившийся с фоном; рамка, невидимая в тёмной теме; тень вместо границы.

Если от темы зависит не цвет, а сам контент (другая картинка, другая иллюстрация) —
хук `useIsDarkTheme` из `@/shared/telegram`. Для цветов он не нужен.

## Размеры и отступы

Только шкала Tailwind: `p-4`, `gap-2`, `text-sm`, `rounded-lg`.
Произвольные значения `w-[137px]` — только для реально уникальных случаев, с комментарием.

Радиусы: `rounded-sm|md|lg|xl` — они привязаны к токену `--radius`.

## Safe area и высота

Мини-апп рисуется под шапкой Telegram и системными вырезами. Есть готовые утилиты:

```tsx
<div className="min-h-viewport pt-safe pb-safe" />
```

| Утилита                         | Что делает                                     |
| ------------------------------- | ---------------------------------------------- |
| `pt-safe` / `pb-safe`           | отступ под безопасную зону сверху/снизу        |
| `h-viewport` / `min-h-viewport` | высота окна мини-аппа без дёрганья при скролле |

Не используй `h-screen` и `100vh` — внутри Telegram они врут.

## Утилита cn

```tsx
import { cn } from '@/shared/lib'

;<div className={cn('flex items-center gap-2', isActive && 'bg-accent', className)} />
```

- Классы всегда через `cn`, если есть условия или внешний `className`.
- `className` от родителя ставится последним, чтобы его можно было переопределить.
- Не склеивай классы шаблонной строкой — `cn` разрешает конфликты Tailwind.

## Варианты компонента

Три и более варианта оформления — `cva`, а не набор тернарников. См. `shared/ui/kit/button.tsx`.

## Порядок классов

Порядок правит `prettier-plugin-tailwindcss` — не сортируй руками, запусти `npm run format`.

## Мобильный контекст

- Приложение всегда узкое: базовые стили — мобильные, `sm:`/`md:` почти не нужны.
- Зона нажатия минимум `size-11` (44 px).
- Не полагайся на `hover:` — на тач-устройствах его нет. Обратная связь — `active:`.
- Длинные экраны скроллятся, липкие панели — `sticky bottom-0 pb-safe`.

## Когда трогать index.css

Только для: нового цветового токена, новой `@utility`, правки `@layer base`.
Компонентные классы в CSS не пишем — всё в Tailwind-классах рядом с разметкой.
