# UX-спека — Frontend

## Секция A · Вход и онбординг

| Макет | Экран                  | Роут                      | Что делает                                                                |
| ----- | ---------------------- | ------------------------- | ------------------------------------------------------------------------- |
| S-01  | Загрузка               | `/`                       | Обменивает Telegram initData на сессию и по статусу решает, куда вести    |
| S-02  | Приветствие и согласие | `/welcome`                | Объясняет продукт, фиксирует согласие с документами                       |
| S-03  | Кто я                  | `/onboarding/about`       | Имя, дата рождения, пол                                                   |
| S-04  | Кого ищу               | `/onboarding/preferences` | Кого показывать, диапазон возраста, цели знакомства                       |
| S-05  | Город                  | `/onboarding/city`        | Определение по геолокации или поиск по каталогу                           |
| S-06  | Фото                   | `/onboarding/photos`      | Импорт из Telegram, загрузка, главное фото, удаление. Завершает онбординг |
| S-07  | Готово                 | `/onboarding/done`        | Начисленные зорки, заполненность карточки, следующая награда              |

### Навигация

```
/ ──► /welcome ──► /onboarding/about ──► /preferences ──► /city ──► /photos ──► /done ──► /home
     (status new)                    ◄── нативная кнопка «Назад» ───┘
```

- На `/` и `/welcome` кнопки «Назад» нет: возвращаться некуда.
- На шагах 2–4 назад можно двумя способами: нативной кнопкой Telegram и стрелкой
  в шапке шага. Оба ведут на предыдущий шаг.
- На шаге 1 стрелки нет: назад только к согласию, а его переспрашивать не нужно.
- На `/done` кнопки «Назад» нет: онбординг уже завершён на сервере.

### Состояния

| Экран      | Загрузка                         | Пусто                                              | Ошибка                                                         |
| ---------- | -------------------------------- | -------------------------------------------------- | -------------------------------------------------------------- |
| S-01       | сам является состоянием загрузки | —                                                  | заголовок + что делать + «Повторить»                           |
| S-02       | —                                | —                                                  | текст над кнопкой, если согласие не сохранилось                |
| S-03, S-04 | скелетон, пока грузится черновик | —                                                  | `ErrorState` с повтором; ошибка сохранения — текст над кнопкой |
| S-05       | скелетон под полем поиска        | «Ничего не нашлось»                                | текст под кнопкой определения, если геолокация не сработала    |
| S-06       | скелетон вместо сетки            | сетка из пустых слотов «+»                         | текст над кнопкой при ошибке загрузки или завершения           |
| S-07       | —                                | карточка заполненности скрыта, если результата нет | —                                                              |

### Правила шагов

- Кнопка внизу неактивна, пока шаг не заполнен: имя и дата на S-03, хотя бы одна цель на S-04,
  выбранный город на S-05, хотя бы одно фото на S-06.
- Возраст на S-04 задаётся и вводом в поле (с суффиксом «лет»), и слайдером — они
  синхронны. Введённое вне границ подтягивается к границе при выходе из поля.
- Целей знакомства шесть, выбрать можно две. Третий выбор вытесняет самый ранний,
  а не блокируется, — так не приходится сначала снимать галочку.
- Каждый шаг сохраняется на сервере отдельно — закрыл приложение, вернулся с того же места.
- Возраст 18+ проверяется и в интерфейсе (список годов), и схемой, и бэкендом.

## Секция B · Лента

| Экран | Что это              | Путь                        |
| ----- | -------------------- | --------------------------- |
| S-10  | Дек карточек         | `/feed`                     |
| S-11  | Шторка полной анкеты | поверх `/feed`              |
| S-14  | Анкеты закончились   | вместо дека при `exhausted` |
| S-15  | Фильтры подбора      | шторка поверх `/feed`       |
| S-16  | Взаимный лайк        | шторка поверх `/feed`       |

### Навигация

Лента — корневой экран после анкеты, уходить с неё некуда, поэтому нативная
кнопка «Назад» показывается только когда открыта шторка, и закрывает её.

Дек показывает одну верхнюю карточку. Остальные приходят тем же запросом и ждут
в кэше, поэтому следующая анкета появляется без ожидания сети.

### Состояния

| Состояние | Что показываем                                              |
| --------- | ----------------------------------------------------------- |
| загрузка  | скелетон на месте карточки                                  |
| пусто     | S-14 с действиями «расширить фильтры», «заполнить карточку» |
| ошибка    | `ErrorState` с повтором                                     |
| нет фото  | градиентная подложка вместо битой картинки                  |

### Правила

- Кнопки крупнее по важности: «нравится» самая большая, «отменить» появляется
  только после своего свайпа и исчезает, когда бесплатные отмены кончились.
- Расстояние меньше километра не пишем: показываем только город.
- Фильтры применяются одной кнопкой, а не на каждое движение ползунка —
  подбор считается серверно.
- Шторка фильтров пересоздаётся при каждом открытии, иначе показывала бы
  прошлые правки вместо сохранённых значений.

## Секция D · От мэтча до свидания

| Экран | Что это         | Путь                          |
| ----- | --------------- | ----------------------------- |
| S-30  | Список мэтчей   | `/matches`                    |
| S-31  | Хаб мэтча       | `/matches/$matchId`           |
| S-32  | Открыть контакт | карточка в хабе               |
| S-33  | Написать первым | шторка поверх хаба            |
| S-37  | Вопрос дня      | `/matches/$matchId/question`  |
| S-39  | Идея свидания   | `/matches/$matchId/date-idea` |

### Правила

- Хаб — единственная точка входа в ветки. Недоступные ветки не прячем, а гасим
  подписью «Пока недоступно»: иначе экран выглядит по-разному у разных пар без объяснения.
- Доступность берём из `features.*` ответа хаба, а не решаем на клиенте. Сегодня
  живые — вопрос дня (когда джоба опубликовала вопрос) и идея свидания.
- `contactStatus: "writes_first_only"` — человек запретил писать себе (S-51).
  Тогда карточку контакта не продаём вовсе, а объясняем, что он напишет сам.
- Сообщение бэкенд не отправляет: текст копируется в буфер, дальше человек пишет
  в Telegram сам.

## Секция E · Профиль и зорки

| Экран | Что это                  | Путь                        |
| ----- | ------------------------ | --------------------------- |
| S-40  | Мой профиль              | `/profile`                  |
| S-42  | Предпочтения на свидания | `/profile/date-preferences` |
| S-43  | Интересы                 | `/profile/interests`        |
| S-46  | Кошелёк зорок            | `/profile/wallet`           |
| S-47  | Пригласить друга         | `/profile/invite`           |

Профиль собирается одним `GET /api/users/me`: возраст, город, фото и интересы
считает сервер. Строки «Как заработать» в кошельке показывают серверный прогресс
и «уже получено»; те, что ведут дальше, отмечены шевроном.

## Секция G · Приватность и безопасность

| Экран | Что это         | Путь                       |
| ----- | --------------- | -------------------------- |
| S-51  | Приватность     | `/profile/privacy`         |
| —     | Заблокированные | `/profile/privacy/blocked` |
| S-13  | Жалоба          | внизу шторки анкеты        |

### Правила

- Тумблеры сохраняются по переключению, без кнопки «Сохранить». Пока запрос в
  полёте, показываем новое положение, иначе тумблер отскакивал бы назад.
- «Режим невидимки» требует подписки: на 422 объясняем это текстом, а не молча гасим.
- Удаление аккаунта — в два нажатия: восстановления в API нет.
- В жалобе причина одна, комментарий необязателен, «заблокировать заодно» —
  отдельное решение и по умолчанию включено.

## Нижнее меню

Пять разделов: Лента, Симпатии, Мэтчи, Идеи, Профиль. Живёт в `RootLayout`
и показывается только на этих пяти путях — вход, анкета и документы без него.

На «Симпатиях» бейдж с числом входящих лайков (`GET /api/likes/incoming`):
это единственное место, где что-то ждёт ответа.

«Идеи» — единственный раздел-заглушка «скоро»: доски идей на бэкенде нет.
Чего не хватает от API по остальным экранам — см. api-gaps.md.
