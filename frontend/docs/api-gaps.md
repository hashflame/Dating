# Пробелы в API

Список мест, где фронт работает на заглушке или обходится неполным контрактом.

Правила:

- Заглушка ставится через `stub()` из `@/shared/api` и помечается комментарием `// @stub: …`.
- Каждая заглушка обязана быть в этой таблице.
- Когда эндпоинт появился — убираем заглушку и строку отсюда.
- В production-сборке `stub()` бросает ошибку, поэтому забытая заглушка не уедет в релиз.

Сверено с деплоем 25.08.2026 (`/openapi/v1.json`, 27 эндпоинтов) и исходниками `backend/`.

## Решено держать на фронте

Это не пробелы, а осознанные решения — чтобы их не начали «исправлять» на бэкенде.

| Что                              | Где живёт                                                | Почему так                                                                                                                                                     |
| -------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Лимит «до двух целей знакомства» | `MAX_GOALS` и zod-схема шага 2                           | Правило продуктовое, а не про целостность данных. Серверную проверку не запрашиваем: обойти его можно только запросом мимо интерфейса, и вреда от этого нет    |
| Тексты Правил и Политики         | `src/shared/i18n/locales/*/common.json`, ключи `legal.*` | Своего сайта у продукта нет, документы читают внутри мини-аппа на экранах `/legal/terms` и `/legal/privacy`. Перевод — часть интерфейса, поэтому и текст рядом |
| Версия согласия                  | `CONSENT_VERSION` в `src/shared/config/legal.ts`         | Уходит на сервер и фиксируется с временной меткой. Поднимать вручную при правке текстов `legal.*` — иначе согласившиеся со старой редакцией не переспросятся   |

## Что нужно от инфраструктуры, а не от кода

| Что                                                        | Когда                        | Почему                                                                                                                                                                                                                                                                                                                           |
| ---------------------------------------------------------- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Токен бота в `TELEGRAM_BOT_TOKEN`                          | сейчас, для локальной работы | Вход требует подлинной подписи initData. Как это устроено — [real-backend.md](real-backend.md)                                                                                                                                                                                                                                   |
| Очистка свайпов: фикс есть, но не задеплоен                | ждёт деплоя бэкенда          | Коммит `014799f` научил `DELETE /api/onboarding/draft` чистить свайпы пользователя, но на стенде работает прежняя версия. Проверено 25.08.2026 двумя способами: описание метода в `/openapi/v1.json` прежнее, и в живом прогоне свайпнутая карточка после сброса и повторного онбординга в ленту не вернулась                    |
| Удаление аккаунта (`DELETE /api/users/me/account`, T-16.1) | не реализовано               | В OpenAPI стенда 28 путей, удаления аккаунта среди них нет. После сброса `userId` тот же — пользователь остаётся. Поэтому «полного сброса» в панели разработки нет: кнопке некуда обращаться                                                                                                                                     |
| Origin фронтенда в `Cors:AllowedOrigins`                   | к первому деплою фронта      | Сейчас заголовки отдаются только для `https://web.telegram.org` — это origin веб-клиента Telegram, а не наш. Мини-апп внутри Telegram грузится в iframe **с нашего домена**, поэтому запросы к API будут кросс-доменными при любом деплое. В dev обходится прокси Vite. Альтернатива CORS — отдавать фронт и API с одного origin |

## Закрыто

Деплой `52ed84e` (25.08.2026) закрыл два пробела симпатий: появился
`GET /api/users/{userId}` с полной анкетой, и `LikesRepository` больше не отдаёт
пользователей со `Status = Deleted`. Открытие анкеты из симпатий подключено, интересы выбираются на шаге 5 онбординга
(`GET /api/interests/catalog`, `/search`, `PATCH /api/users/me/interests`).

Деплой `014799f` (25.08.2026) научил `DELETE /api/onboarding/draft` чистить свайпы пользователя.
Проверено живым прогоном: свайпнутая карточка после сброса возвращается в ленту. Отдельный
эндпоинт очистки свайпов больше не нужен, «Сброс пользователя» в панели разработки закрывает это.

Деплой 25.08.2026 (`3af61fe`) закрыл почти весь прошлый список:

- `GET /api/users/me` — профиль с балансом; заглушка `useViewer` убрана, баланс настоящий.
- `status` в ответе входа — camelCase; приведение регистра из `use-session.ts` удалено.
- Ссылки на фото — новые загрузки открываются (был задвоенный префикс бакета).
- `import-telegram` — 422 `PHOTO_DOWNLOAD_FAILED` вместо 500.
- `DELETE /api/onboarding/draft` — сброс регистрации; на нём построены dev-сбросы.
- `GET /api/sparks/wallet`, хаб мэтча и `unlock` задеплоены.
- OpenAPI: убраны `["integer","string"]`, у `draft.data` появились схемы шагов.

### Раньше

Эти пробелы были и закрылись деплоем от 24.08.2026 — оставлено, чтобы не искать заново:

- `GET /api/users/me/photos` — список фото; заглушка убрана, фото не теряются после перезагрузки.
- `GET /api/cities/{cityId}` — город по id; шаг «Где вы?» восстанавливает сохранённый выбор.
- `GET /api/users/me/consent` — статус согласия; стартовый экран больше не угадывает его по `draft.step`.
- `DatingGoal` — энум расширен до всех шести целей макета (плюс `notSureYet`, которого на экране нет).
- `ConsentType`/`DatingGoal`/`UserStatus` в спеке описаны как `integer` — это артефакт генератора OpenAPI.
  Реально работает `JsonStringEnumConverter(camelCase)` из `ApiServiceCollectionExtensions`, то есть строки.
