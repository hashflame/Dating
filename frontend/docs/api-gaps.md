# Пробелы в API

Где фронт работает на заглушке или обходится неполным контрактом.

Правила:

- Заглушка — через `stub()` из `@/shared/api`, с комментарием `// @stub: …` и строкой в этом файле.
- Эндпоинт появился — убираем заглушку и строку отсюда.
- В production `stub()` бросает, поэтому забытая заглушка падает на сборке.

Сверено с исходниками `backend/` (по коммит `94453a5`, 27.08.2026) и живым
прогоном. Фронт не зовёт `reseed-demo-data` (нужен серверный секрет, сносит
всех демо-юзеров) и `message-sent-check` (решение ниже).

## Заглушки

Сообщения и суперсообщения сделаны на заглушках: эндпоинтов нет совсем,
тикеты на бэкенд заведены.

| Где                                           | Заглушка                   | Что нужно от API                                                                                                              |
| --------------------------------------------- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `domains/messaging/api/use-message-limits.ts` | `GET /api/messages/limits` | недельные лимиты переходов в чат (10 сообщений, 1 суперсообщение), `resetsAt`, цена сверх лимита (✦3 и ✦10) и баланс зорок    |
| `domains/messaging/api/use-open-chat.ts`      | `POST /api/messages`       | проверка, что писать этому человеку можно, списание зорок за переход сверх лимита и ссылка на личку `https://t.me/<username>` |

Приложение сообщения **не доставляет**: оно готовит текст, кладёт его в буфер
и открывает личку Telegram. Плата берётся за переход, а не за доставку.

Пока заглушка на месте, черновая касса лимитов живёт в модуле
`use-message-limits.ts`: переход списывает из неё, чтобы в dev были видны все
состояния — бесплатные есть, кончились, зорок не хватает. Уедет вместе с `stub()`.

## Что проверено на живых аккаунтах

Прогон 27.08.2026 на трёх свежих аккаунтах (Минск ×2 + Жодино). Расстояние
считается от координат города, поэтому пара в одном городе даёт 0 км — для
проверки нужен второй город. Второй прогон после коммита `ad1fb30` — под ним
отдельная пометка «(27.08, второй прогон)».

| Настройка                   | Где применяется                                                                                                                  |

| «Запретить писать мне»      | хаб мэтча — да, «Входящие закрыты»/`locked`, переключается с сервера верно (27.08, второй прогон)                                |
