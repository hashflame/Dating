# Пробелы в API

Список мест, где фронт работает на заглушке или обходится неполным контрактом.

Правила:

- Заглушка ставится через `stub()` из `@/shared/api` и помечается комментарием `// @stub: …`.
- Каждая заглушка обязана быть в этой таблице.
- Когда эндпоинт появился — убираем заглушку и строку отсюда.
- В production-сборке `stub()` бросает ошибку, поэтому забытая заглушка не уедет в релиз.

## Расхождение задеплоенного бэкенда с исходниками

Проверено 20.08.2026 против `https://api-production-3ead.up.railway.app`
(`/api/health` — `Healthy`, postgres — `healthy`).

Спецификация задеплоенной сборки лежит на `/openapi/v1.json` и описывает
**8 эндпоинтов** — меньше, чем есть в `backend/`. Отсюда следствия:

| Что                                          | Локальные исходники                          | Задеплоенная сборка  | Что это значит для фронта                                               |
| -------------------------------------------- | -------------------------------------------- | -------------------- | ----------------------------------------------------------------------- |
| `GET /api/cities/search`                     | есть                                         | **404**              | шаг «Где вы?» на деплое не работает — нечем искать город                |
| `POST /api/geo/detect`                       | есть                                         | **404**              | кнопка «Определить автоматически» на деплое вернёт ошибку               |
| `ConsentType` в `POST /api/users/me/consent` | строка camelCase (`JsonStringEnumConverter`) | `{"type":"integer"}` | после редеплоя перепроверить: отправляем строку `termsAndPrivacyPolicy` |

Пока деплой не обновлён, сквозная проверка в браузере идёт против локальной
заглушки (`VITE_API_PROXY_TARGET=http://localhost:5000`). Отдельно: подменённый
`initData` реальный сервер не принимает — `POST /api/auth/telegram` отвечает
`401 TELEGRAM_INIT_DATA_INVALID`, что ожидаемо и подтверждает проверку подписи.
