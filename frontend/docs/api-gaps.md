# Пробелы в API

Где фронт работает на заглушке или обходится неполным контрактом.

Правила:

- Заглушка — через `stub()` из `@/shared/api`, с комментарием `// @stub: …` и строкой в этом файле.
- Эндпоинт появился — убираем заглушку и строку отсюда.
- В production `stub()` бросает, поэтому забытая заглушка падает на сборке.

Сверено с исходниками `backend/` (по коммит `ad1fb30`, 27.08.2026) и живым
прогоном. Фронт не зовёт `reseed-demo-data` (нужен серверный секрет, сносит
всех демо-юзеров) и `message-sent-check` (решение ниже).

## Заглушки

Одна фича целиком на заглушках — доска идей (T-19.1 помечена `POST-MVP`, на бэкенде
есть только сущности `Idea`/`IdeaVote`, ни контроллера, ни use-case'ов).

| Место в коде                               | Что нужно от API                          |
| ------------------------------------------ | ----------------------------------------- |
| `src/domains/ideas/api/use-ideas.ts`       | `GET /api/ideas` — список доски (S-60)    |
| `src/domains/ideas/api/use-create-idea.ts` | `POST /api/ideas` — `{ text, anonymous }` |
| `src/domains/ideas/api/use-vote-idea.ts`   | `POST`/`DELETE /api/ideas/{ideaId}/vote`  |

Чего не хватает в самом контракте T-19.1, помимо реализации:

- `?sort=hot|new` не покрывает вкладки макета «В работе» и «Мои» — нужен фильтр
  по статусу и по автору.
- В ответе нужен `hasVoted`: без него не показать, за что уже голосовал, и
  кнопка не может быть переключателем.
- `POST /api/ideas` должен сказать, начислена ли зорка за эту идею: бонус даётся
  раз в месяц, и человеку важно понимать, что идея принята, но зорки не пришли.

Остальные заглушки убраны: реферальные ссылки, блокировка и жалобы поехали на
реальные эндпоинты (T-20.1, T-16.2, T-17.1).

## Что проверено на живых аккаунтах

Прогон 27.08.2026 на трёх свежих аккаунтах (Минск ×2 + Жодино). Расстояние
считается от координат города, поэтому пара в одном городе даёт 0 км — для
проверки нужен второй город. Второй прогон после коммита `ad1fb30` — под ним
отдельная пометка «(27.08, второй прогон)».

| Настройка                   | Где применяется                                                                                                           |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| «Скрывать расстояние»       | лента: было «Жодино, 55 км от вас» → стало «Жодино»                                                                       |
| «Скрывать возраст»          | лента, симпатии, мэтчи, хаб, анкета, превью — везде (27.08, второй прогон): `GET /api/matches` живьём отдал `"age": null` |
| «Запретить писать мне»      | хаб мэтча — да, «Входящие закрыты»/`locked`, переключается с сервера верно (27.08, второй прогон)                         |
| «Показывать был(а) недавно» | лента — да, по коду и по ответу                                                                                           |
| «Режим невидимки»           | нигде — см. «Баги бэкенда»                                                                                                |
| Фильтр по расстоянию        | при 50 км кандидат в 55 км не приходит, при 200 км приходит                                                               |

Заодно `ad1fb30`/`be1f8ee` закрыли три бага, которых в этом файле не было —
