# shared/ui

Переиспользуемые компоненты, собранные по макетам. `kit/` — примитивы shadcn,
добавляются командой `npx shadcn@latest add <имя> --yes`.

## Что где брать

| Нужно                                                                                                | Импорт                                                     |
| ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Кнопка, поле ввода, чекбокс, скелетон, карточка, полоса прогресса, логотип, пустое состояние, ошибка | `@/shared/ui`                                              |
| Выбор одного из 2–3 вариантов: пол, кого показывать                                                  | `@/shared/ui/SegmentedControl`                             |
| Крупный вариант выбора в сетке: цели знакомства                                                      | `@/shared/ui/OptionCard` (внутри `ToggleGroup`)            |
| Строка списка с галочкой выбранного: города, интересы                                                | `@/shared/ui` → `ListRow`                                  |
| Неинтерактивная метка: интерес, ценность                                                             | `@/shared/ui/Tag`                                          |
| Строка «подпись — тумблер»: списки настроек                                                          | `@/shared/ui/SwitchRow`                                    |
| Фото с точками и переключением тапом                                                                 | `@/shared/ui/PhotoCarousel`                                |
| Иконка к варианту выбора, привычке, требованию                                                       | `@/shared/ui/icons`                                        |
| Диапазон чисел с полями и слайдером                                                                  | `@/shared/ui/RangeField`                                   |
| Группа переключателей, выпадающий список, слайдер                                                    | `@/shared/ui/kit/toggle-group`, `kit/select`, `kit/slider` |

Тяжёлые radix-примитивы (`toggle-group`, `select`, `slider`, `sheet`, `switch`)
сознательно **не** реэкспортируются из `index.ts`: барель попадает в главный чанк,
и тогда они уезжают туда же, даже если нужны только одному экрану.
Импортируй их по прямому пути — так они остаются в чанке своей страницы.

## Иконки

Общий набор — `lucide-react`. Своё рисуем в `icons/` только там, где эмодзи
стояло как иконка: эмодзи рисуется шрифтом платформы, поэтому одна и та же
карточка выглядит на iOS и на Android по-разному, а на залитой выбранной
карточке цветная картинка не наследует цвет.

Новая иконка — файл в `icons/<Имя>Icon.tsx` поверх обвязки `Icon` и строка
в `icons/index.ts`. Размер задаётся классом снаружи (`size-5`), как у lucide.

Метрика одна на весь интерфейс — та же, что у lucide, иначе свои иконки
выпадают из строки с библиотечными:

- сетка 24×24, штрих 2, скруглённые концы и стыки, цвет — `currentColor`;
- рисунок вписан в поле 2…22 по большей стороне: набор не должен «прыгать»
  по размеру от иконки к иконке;
- скругление крупных прямоугольников — 3, точки — залитые кружки радиуса 1.2,
  перечёркивание запретов — одна и та же диагональ `M3.9 20.1 20.1 3.9`.
