# Блізка — монорепо

Дейтинг-продукт в формате Telegram Mini App.

```
dating/
├── backend/    — API (собственные правила, см. backend/CLAUDE.md)
└── frontend/   — Telegram Mini App (React + Vite)
```

Пакеты самодостаточны: свои зависимости, команды, соглашения и скиллы.
Работая над одним пакетом, не меняй файлы другого.

## Frontend

Точка входа — [`frontend/CLAUDE.md`](frontend/CLAUDE.md): обязательный порядок работы,
стек, структура, команды, что можно и что нельзя.

Правила разложены по скиллам в `frontend/.claude/skills/`:

- `fe-*` — как писать код фронтенда (архитектура, компоненты, стили, данные,
  состояние, формы, Telegram, роутинг, тексты, тесты, производительность, самопроверка).
- `bmad-*` — процесс разработки с агентами: роли, артефакты, цикл историй.
  Начни со скилла `bmad`.

Скиллы подхватываются по смыслу задачи — называть их в запросе не нужно.

## Backend

Правила и команды — в [`backend/CLAUDE.md`](backend/CLAUDE.md).

Фронтенду папка `backend/` нужна только как **источник истины по контракту API**:
оттуда читаются DTO, маршруты и коды ошибок. Читать — да, менять — нет.
Как это делать: скилл `fe-api-contract`.
